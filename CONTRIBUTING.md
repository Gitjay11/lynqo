# Contributing to Lynqo

Thank you for your interest in contributing!

## How to Contribute

- Bug fixes — open an issue first describing the bug
- New features — open an issue first to discuss before building
- UI improvements — screenshots or mockups welcome in the PR
- Documentation — always welcome, no issue needed

## Code Style

- Use meaningful variable and function names
- Comment complex logic
- Follow the existing folder structure
- Mobile-first for all frontend changes

## Pull Request Rules

- One feature or fix per PR
- Test your changes before submitting
- Update README if you add something new
- Be respectful in reviews
